# GitHub Copilot CLI - Dicee DevOps Config

Copilot CLI remains useful for Dicee DevOps and verification workflows, but the repo no longer modifies your global Copilot config automatically.

## Quick Reference

```bash
./scripts/copilot-mcp-wrapper.sh quality-gate
./scripts/copilot-mcp-wrapper.sh deploy-check
./scripts/copilot-mcp-wrapper.sh deploy-full
./scripts/copilot-mcp-wrapper.sh tail-logs
./scripts/copilot-mcp-wrapper.sh check-env
```

## Auth Model

- Cloudflare operator auth is resolved through `./scripts/with-dicee-cloudflare.sh`
- Runtime/app secrets stay in Infisical
- GitHub and Context7 auth are global/user-baseline concerns

## Manual Copilot Setup

Use `.copilot-mcp.json` as the repo-owned template, replace `/absolute/path/to/dicee` with your local checkout path, and then merge it into your own `~/.copilot/mcp-config.json` manually if you want those MCP servers exposed in Copilot CLI.

## Verification

```bash
direnv allow
./scripts/check-1password-setup.sh
./scripts/copilot-mcp-wrapper.sh check-env
```
